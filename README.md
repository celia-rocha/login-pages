## 📖 Sobre o Projeto

O Login Pages é um projeto focado em criar uma tela de autenticação moderna, limpa e responsiva. O projeto tem como objetivo proporcionar uma experiência visual elegante, utilizando uma estética de "Glassmorphism" (efeito de vidro) e um fundo desfocado dinâmico, garantindo um design com aspecto premium.

### ✨ Destaques

- 🎨 **Design Elegante** - Interface de vidro (glassmorphism) com toques sofisticados e limpos.
- 🔒 **Usabilidade** - Inputs focados, botões visíveis e estrutura familiar para o usuário comum.
- ⚡ **Alta Performance** - Estilos feitos inteiramente com **Tailwind CSS v4**, sem classes CSS globais pesadas.
- 💖 **Efeitos Premium** - Transições suaves (hover e focus effects), com ícones e bordas que reagem ativamente à digitação.

## 🎯 Funcionalidades

- ✅ Layout de Login 100% responsivo e centralizado.
- ✅ Efeito Glassmorphism avançado.
- ✅ Captura de estado dos formulários (`useState`).
- ✅ Design system configurado direto no JSX (Utility-first).

## 🚀 Como Executar Localmente

```bash
# Clone o repositório
git clone https://github.com/celia-rocha/login-pages.git

# Entre na pasta
cd login-pages

# Instale as dependências
npm install

# Execute o projeto
npm run dev
```
